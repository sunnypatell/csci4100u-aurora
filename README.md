# csci4100u-course-project
Final Course Projected TBD Stack - Repo made

for installing firebase DB to get app running in development:

`flutter pub get` to install dependencies.
Then run
`npm i -g firebase-tools` to install firebase cli.
Then run
`firebase login` to login to your firebase account.
Then run
`dart pub global activate flutterfire_cli` to install flutterfire cli.
Then run
`flutterfire configure` to configure firebase for the project.
Finally run
`flutter run` to run the app.
